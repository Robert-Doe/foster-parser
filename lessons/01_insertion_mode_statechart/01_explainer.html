The Insertion ModeStatechart

The real spec has ~20 insertion modes. This course's engine ended up with roughly six. This page is the map of exactly which real modes survived, which got merged, and — most importantly — where that merging was free and where it cost something.

01

The Big Analogy

Imagine translating a twenty-room office building into a six-room apartment, on the theory that most of the twenty rooms were only ever used for one specific, narrow purpose that a shared room could handle just as well. Most of the time, nobody notices the difference — the shared room handles whatever comes in correctly. Then, one day, something arrives that behaves differently depending on which of the original twenty rooms it would have been in, and the shared room gets it wrong, because it genuinely can't tell which of the original rooms this visitor "belongs" in anymore. That day is Module 11's Bug 2.

03

Where the collapse was free, and where it wasn't

Free (Modules 05–10): every test case through Module 10 that involved a ``/``/`` current node behaved identically whether the engine called its mode "in table" or the real spec's "in row"/"in cell," because the ONE thing that actually varies by current-node-family — the foster-parenting gate (Module 02) — checks current node identity directly, never the mode's name. Module 05's own DECISIONS.md argues this explicitly and Module 08 independently re-derives the same conclusion for buffered character content.

Not free (Module 11): the real in template mode doesn't just relabel in table body/in row — it skips the tbody-implying step those modes perform when reached the normal way, dispatching <tr> straight to a mode that inserts it directly. That skip is a genuinely separate rule this engine's collapsed model has no way to express, because collapsing erased the seam where that rule would attach. Module 11 didn't fix this — it changed its test input to avoid the seam entirely, and said so.

The general lesson

Collapsing two states into one is safe exactly as long as nothing downstream ever needs to ask "wait, which of the two original states was this, really?" The gate (Module 02) never asks that question — it asks a different, current-node-shaped question that happens to give the same answer either way. The in template mode-dispatch table DOES ask that question, directly, by name. That's the precise, checkable difference between the modules where collapsing cost nothing and the one where it did.
